## Partial implementation currently present

Only `agent/rules.py` has been patched. The patch adds a shared
`_reduce_survival_arbitration(...)` reducer and normalization helpers for
active IDs and incident records. The reducer is intended to be used by both
the direct arbiter and the certificate validator. It compares strict boolean
and list types, retains canonical rank order, treats non-open records as
invalid only when their pause ID is active, preserves retained inactive
history for non-active IDs, and records open pause witnesses outside the
active set. The certificate shape is now represented by a closed
`frozenset`, with the existing schema string
`oni.survival-arbitration.v1`.

`arbitrate_survival_emergency(...)` now prepares trusted state/contract
context and calls the shared reducer. `build_survival_arbitration_certificate`
now passes its supplied incident view to that path rather than filtering all
records to `status == open` first. The certificate validator has been replaced
with a shared-reducer comparison of status, game-paused state, active IDs,
eligible IDs, selection, blockers, and command-hint hash. It also has a
restricted safe escape for producer-side blocked projections caused by
`state_unavailable`, `state_not_trusted_live`, `alerts_contract_unusable`, or
`paused_contract_unusable`; those projections must have no active/eligible or
selected command payload and may not carry arbitrary blocker reasons.

This patch has not yet been compiled or behaviorally verified. It may need a
small corrective patch before any other source is changed. In particular,
the continuation task must check the call ordering, certificate validation
against retained incident history, and whether a frame source without
`snapshot_seq` needs a narrow compatibility binding. Do not assume the
partial patch is correct merely because the old reproduction is known.
